# SinSO ontology and lab-case instantiation

**SinSO ontology:** published in Mendeley Data (CC BY 4.0):
Restrepo Gutierrez, L. F. (2023). *SINSO Ontology*, Mendeley Data, V2.
https://doi.org/10.17632/ygv49pb4dx.2

**TO BE ADDED BY THE AUTHORS before publishing this repository** (the lab-case instantiation
used in the paper):

- `SinSO_ERM-HS1.owl`: the instantiation of the ERM-HS1 lab case (individuals for the
  quality attributes, goals, indicators and metrics), importing SinSO.
- `competency_questions.sparql`: the queries that answer CQ1, CQ7 and CQ8.

How to check: open `SinSO_ERM-HS1.owl` in Protégé (5.6+), start the HermiT reasoner
(Reasoner > HermiT > Start reasoner) and verify that the ontology is consistent; run the
queries in the SPARQL Query tab.
